# Imam Bargah Baqiyatullah Islamic Center

A responsive, multilingual first-version website for Imam Bargah Baqiyatullah Islamic Center in Málaga, Spain.

## Current structure

- `index.html` — page structure and institution-specific content
- `styles.css` — responsive styling, color system, layout and RTL adjustments
- `script.js` — Spanish, English and Urdu language switching, mobile navigation and active section state

## Languages

Spanish is the default language. English and Urdu are available from the header language selector. Urdu sets the document direction to right-to-left.

## Preview locally

Because this is a static website, no build step is required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. An internet connection is needed for the hosted fonts and remote decorative photography.

For a more representative local preview, run a simple static server from the repository folder, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
